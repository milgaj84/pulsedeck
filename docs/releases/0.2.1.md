# PulseDeck 0.2.1 Release Notes

PulseDeck 0.2.1 focuses on keyboard compatibility, station inspection, session track listings, and terminal theme support.

## What's New in 0.2.1

### 1. Key Improvements & UX Polishing
- **Tolerate Terminal Modifiers**: Normal mode shortcuts are designed to work across various terminal emulators, bypassing terminal-added modifiers (e.g. Shift/Alt) to improve compatibility.
- **Adaptive Footer**: The footer now displays contextually relevant keyboard shortcuts dynamically instead of overwhelming the user with all keybinds.

### 2. Overlays & Context
- **Station Details Overlay (`i`)**: Inspect the highlighted station's metadata, genre, country, bitrate, and direct stream URL.
- **Recent Tracks Overlay (`g`)**: Shows a list of recent stream-provided track titles heard during the current session.
- **Empty Library Onboarding**: Features an onboarding card for first-run users to guide them through adding their first stations.

### 3. Audio & Themes
- **Manual Stream Retry (`r`)**: Instantly retry the active stream if a network hiccup or temporary dropout causes a playback error.
- **Terminal Theme**: A new terminal-native theme that uses your terminal emulator's ANSI palette and reset backgrounds.
