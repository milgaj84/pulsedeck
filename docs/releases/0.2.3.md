# PulseDeck 0.2.3 Release Notes

PulseDeck 0.2.3 is a code-quality and maintainability release for the 0.2 radio player line.

## Highlights

- Sleep timers now wait for playback before spending their countdown.
- UI helpers, deck rendering, theme palettes, and visualizer DSP are split into focused modules.
- Overlay state is modeled with a single active overlay instead of independent booleans.
- App state is grouped into navigation, search, playback, overlay, notice, and persistence structs.
- Library, history, and UI-state persistence now share config-path helpers and debounced app-level flushing.
- The audio status poller is flatter, and the blocking audio engine loop now lives in `src/audio/engine_loop.rs`.

No new user-facing workflows were added in this release.
