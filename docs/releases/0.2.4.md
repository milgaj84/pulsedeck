# PulseDeck 0.2.4 Release Notes

PulseDeck 0.2.4 is a release-hygiene and reliability patch for the 0.2 radio player line.

## Highlights

- Unknown CLI commands now fail clearly instead of falling through to the TUI.
- CLI exports create missing parent directories for nested output paths.
- Recent Tracks and persistent Listening History wording is clearer in the README and in-app panel.
- Config load failures surface warnings while PulseDeck keeps startup safe with defaults or starter stations.
- Low-priority buffer telemetry and theme-palette access are more defensive around poisoned locks.

No new user-facing workflows were added in this release.
