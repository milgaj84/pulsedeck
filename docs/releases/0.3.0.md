# PulseDeck 0.3.0 Release Notes

PulseDeck 0.3.0 deepens the station discovery loop without broadening the app beyond focused live radio.

## Highlights

- Search now supports focused prefixes such as `tag:ambient`, `country:BA`, `lang:english`, and `codec:mp3`.
- Plain text still searches station names, so existing search habits keep working.
- Search results preserve richer Radio Browser metadata when available.
- Station Details now shows trust signals like tags, codec, bitrate, country code, language, last-check status, homepage, UUID, votes, and recent click count.
- Results are deduplicated and ranked locally so better matches rise to the top.
- Saved search results are detected by station UUID when possible, not only exact stream URL.

## Search prefixes

Examples:

```text
tag:ambient
country:BA
country:Bosnia
lang:english
codec:mp3
name:lofi
```

No recording, local tape, or audio-backend expansion is included in this release.
