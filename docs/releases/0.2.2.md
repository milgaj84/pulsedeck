# PulseDeck 0.2.2 Release Notes

PulseDeck 0.2.2 is a reliability and quality-of-life release built on top of the 0.2 radio player. This release focuses on making stream playback resilient to network dropouts, remembering track history across restarts, adding a sleep timer, and enabling library import/export via the TUI and a new command-line interface.

## New Features & Enhancements

### 1. Auto-Reconnect on Stream Drops
When a stream unexpectedly disconnects or errors, PulseDeck will now automatically attempt to reconnect.
- Retries up to **3 times** with exponential backoff (**3s, 6s, 12s**).
- Displays connection progress in the status bar (e.g. `Reconnecting (1/3)`).
- Manual retry (`r`) remains functional and resets the retry counter.
- User-initiated stops or pauses do not trigger reconnection.

### 2. Persistent Track History
Track history can now persist across application restarts.
- **Opt-in setting**: Respects user privacy. Enable `Save song history` in the Settings panel (`,`).
- When enabled, song history is stored in `history.json` and capped at **500 entries** (newest first).
- The recent tracks overlay (`g`) displays persistent tracks (showing station name and relative age) when enabled, and session tracks when disabled.

### 3. Sleep Timer
A new sleep timer allows you to fall asleep to your favorite stations without playing audio indefinitely.
- Press **`t`** to cycle the timer: **Off → 15 → 30 → 45 → 60 → 90 minutes**.
- Displays remaining time in the status bar with a sleep icon (e.g., `💤 14:59`).
- At expiry, playback automatically fades out, stops, and displays a notice.

### 4. Library Import / Export
Moving your library between machines or backing it up is now simple.
- **In-App Export**: Press **`e`** in normal mode to export your library to `.m3u` in the config directory. A notice will display the exported file path.
- **Headless CLI**: Command line interface for scripting or migrations:
  - `pulsedeck export <path>`: Exports saved library to M3U or JSON format (determined by path extension).
  - `pulsedeck import <path>`: Imports and merges stations from M3U or JSON files into the saved library (deduplicated by URL).
  - `pulsedeck --help` or `-h`: Shows CLI usage information.
  - `pulsedeck --version` or `-V`: Shows version information.

## Bug Fixes & Improvements
- **Unmapped Keys**: Confirmed keys `t` and `e` were unmapped in normal mode to prevent shortcut collisions.
- **Tick Accuracy**: Instant deadlines are used instead of tick counting to prevent timing drift in sleep timers and auto-reconnect backoffs when TUI input suppresses tick events.
