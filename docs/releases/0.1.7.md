# PulseDeck 0.1.7

Release date: 2026-06-01

PulseDeck 0.1.7 is a usability, routing, and resilience release focused on making search, settings, audio output, recording filters, stream buffering, and deck visuals feel more dependable in real terminals.

## Highlights

- Added selectable audio output devices, including Default and backend-exposed outputs such as pulse, pipewire, speakers, or Bluetooth devices.
- Suppressed native ALSA/JACK probe diagnostics during output discovery and opening so backend warnings do not overwrite the TUI.
- Added search-mode audio escape rails: Ctrl/Alt volume and mute shortcuts work without abandoning the active search query.
- Added search audition with Space / Ctrl+Enter, so global search results can be previewed without saving them to the Library.
- Added stale async search response telemetry so late discarded search results are visible instead of silently disappearing.
- Improved settings controls with bidirectional stepping and fine Min Song Duration control from 15s to 600s.
- Added bounded 10-entry undo history for removed Library stations.
- Improved visual continuity during stream connection and audio fade-out states.
- Improved spectrum response for high-frequency treble texture.
- Added critical engine error banners inside help/settings overlays so stream failures remain visible when modals are open.
- Updated README, in-app help, and testing docs to match the new settings, audio output, and search controls.

## Validation

cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-targets --all-features
cargo build --release
cargo publish --dry-run

## Notes for Linux, PipeWire, PulseAudio, and WSL users

If your Bluetooth headphones appear directly in Audio Output, select them in PulseDeck.

If PulseDeck only shows Default, pulse, or pipewire, select the matching backend entry in PulseDeck and route that backend sink to your headphones using wpctl, pavucontrol, or your desktop sound settings.
