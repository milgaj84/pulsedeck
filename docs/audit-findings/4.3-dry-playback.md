## DRY-PB-01: Buffer/Track Reset Triple

**Pattern:** Reset `current_track`, `buffer_percent`, and `buffer_seconds` to their zero/None defaults.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/playback.rs` | `send_audio_command` | 31–33 |
| 2 | `src/app/playback.rs` | `validate_station_playback_capability` | 86–88 |
| 3 | `src/app/playback.rs` | `retry_stream` | 121–123 |
| 4 | `src/app/lifecycle.rs` | `handle_audio_stopped` | 283–285 |
| 5 | `src/app/lifecycle.rs` | `handle_audio_error` | 303–305 |

**Repeated code (5 occurrences):**
```rust
self.playback.view.current_track = None;
self.playback.view.buffer_percent = 0;
self.playback.view.buffer_seconds = 0;
```

**Proposed abstraction:**
```rust
// In PlaybackView
impl PlaybackView {
    pub fn reset_transient_status(&mut self) {
        self.current_track = None;
        self.buffer_percent = 0;
        self.buffer_seconds = 0;
    }
}
```
- **Target module:** `src/app/playback.rs` (on `PlaybackView` impl)
- **Variation points:** None — the pattern is identical in all sites.

## DRY-PB-03: Dead Audio Engine Error State Setup

**Pattern:** When the audio command channel is closed or a codec is unsupported, set `state = Error(...)`, `decoder_state = Failed`, `last_error = Some(...)`, and call `set_error_notice(...)`.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/playback.rs` | `send_audio_command` | 34–38 |
| 2 | `src/app/playback.rs` | `validate_station_playback_capability` | 89–101 |

**Repeated structure:**
```rust
self.playback.view.state = PlaybackState::Error(/* message */);
self.playback.diagnostics.decoder_state = DecoderState::Failed;
self.playback.diagnostics.last_error = Some(/* detail */);
self.set_error_notice(/* user-visible message */);
```

**Proposed abstraction:**
```rust
impl App {
    fn enter_playback_error(
        &mut self,
        state_message: String,
        diagnostic_detail: String,
        notice: impl Into<String>,
    ) {
        self.playback.view.state = PlaybackState::Error(state_message);
        self.playback.diagnostics.decoder_state = DecoderState::Failed;
        self.playback.diagnostics.last_error = Some(diagnostic_detail);
        self.set_error_notice(notice);
    }
}
```
- **Target module:** `src/app/playback.rs`
- **Variation points:** `state_message`, `diagnostic_detail`, `notice` text.

## DRY-PB-04: Play-and-Sync-Volume Sequence

**Pattern:** Issue `AudioCommand::Play(url)` via `send_audio_command` and immediately call `sync_volume()` on success.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/playback.rs` | `play_selected` | 65–67 |
| 2 | `src/app/playback.rs` | `retry_stream` | 124–126 |
| 3 | `src/app/lifecycle.rs` | `apply_startup_autoplay` | 163–165 |
| 4 | `src/app/reconnect.rs` | `drive_reconnect` | 67–69 |

**Repeated code (4 occurrences):**
```rust
if self.send_audio_command(AudioCommand::Play(url)) {
    self.sync_volume();
}
```

**Proposed abstraction:**
```rust
impl App {
    fn start_stream(&mut self, url: String) -> bool {
        if self.send_audio_command(AudioCommand::Play(url)) {
            self.sync_volume();
            true
        } else {
            false
        }
    }
}
```
- **Target module:** `src/app/playback.rs`
- **Variation points:** None — all sites pass a URL and sync volume on success.

## DRY-PB-06: Reconnect Disarm + State Reset

**Pattern:** Call `reconnect.disarm()` as part of a broader state change (either before playing or after stopping/encountering unsupported codec).

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/playback.rs` | `play_selected` | 56 |
| 2 | `src/app/playback.rs` | `validate_station_playback_capability` | 92 |
| 3 | `src/app/lifecycle.rs` | `handle_audio_stopped` | 290 |
| 4 | `src/app/lifecycle.rs` | `poll_audio_status` (Playing handler) | 193 |

**Analysis:** Although `disarm()` is a single method call, it always appears within a stereotyped sequence: stop/reset transient state → disarm reconnect → transition state. Callers duplicate the surrounding context each time.

**Proposed abstraction:** The buffer reset (DRY-PB-01) + reconnect disarm could be combined into a single "reset for new playback attempt" helper:
```rust
impl App {
    fn reset_for_playback_attempt(&mut self) {
        self.playback.view.reset_transient_status();
        self.playback.reconnect.disarm();
    }
}
```
- **Target module:** `src/app/playback.rs`
- **Variation points:** Some sites also clear `playing_url`; this can be an optional flag.

## DRY-PB-07: Volume Adjustment Pattern

**Pattern:** `volume_up` and `volume_down` share identical structure: compute progressive step, apply saturating arithmetic, call `sync_volume()`, call `mark_ui_state_dirty()`.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/playback.rs` | `volume_up` | 174–179 |
| 2 | `src/app/playback.rs` | `volume_down` | 182–186 |

**Repeated structure:**
```rust
let step = progressive_volume_step(self.playback.volume);
self.playback.volume = self.playback.volume.saturating_add/sub(step)...;
// (volume_up also sets muted = false)
self.sync_volume();
self.mark_ui_state_dirty();
```

**Proposed abstraction:**
```rust
impl App {
    fn adjust_volume(&mut self, direction: VolumeDirection) {
        let step = progressive_volume_step(self.playback.volume);
        match direction {
            VolumeDirection::Up => {
                self.playback.volume = self.playback.volume.saturating_add(step).min(100);
                self.playback.muted = false;
            }
            VolumeDirection::Down => {
                self.playback.volume = self.playback.volume.saturating_sub(step);
            }
        }
        self.sync_volume();
        self.mark_ui_state_dirty();
    }
}
```
- **Target module:** `src/app/playback.rs`
- **Variation points:** Direction (up/down), unmute-on-up behavior.

## DRY-PB-08: Stopped-State Full Reset Sequence

**Pattern:** When playback intentionally stops, a full reset of the view + diagnostics is performed.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/lifecycle.rs` | `handle_audio_stopped` (intentional branch) | 282–290 |

**Code:**
```rust
self.playback.view.intentional_stop = false;
self.playback.view.playing_url = None;
self.playback.view.current_track = None;
self.playback.view.buffer_percent = 0;
self.playback.view.buffer_seconds = 0;
self.playback.view.state = PlaybackState::Stopped;
self.playback.diagnostics.decoder_state = DecoderState::Idle;
self.playback.diagnostics.buffer_percent = 0;
self.playback.diagnostics.buffer_seconds = 0;
self.playback.diagnostics.last_event = Some("Playback stopped".to_string());
self.playback.reconnect.disarm();
```

**Analysis:** This 11-line reset is a superset of DRY-PB-01 + DRY-PB-02. Currently only one occurrence, but it represents the canonical "full stop" reset that other partial resets approximate. Extracting `PlaybackView::reset_to_stopped()` and `PlaybackDiagnostics::reset_to_idle()` would make partial resets compose from the same building blocks.

**Proposed abstraction:**
```rust
impl PlaybackView {
    pub fn reset_to_stopped(&mut self) {
        self.intentional_stop = false;
        self.playing_url = None;
        self.current_track = None;
        self.buffer_percent = 0;
        self.buffer_seconds = 0;
        self.state = PlaybackState::Stopped;
    }
}
```
- **Target module:** `src/app/playback.rs`
