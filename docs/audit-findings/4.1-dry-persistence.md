# 4.1 DRY Violations — Persistence and Configuration Patterns

**Scope:** `src/history.rs`, `src/favorites.rs`, `src/config.rs`, `src/playlist.rs`, `src/app/ui_state.rs`, `src/app/persist.rs`, `src/app/` (notice patterns)  
**Requirements:** 2.1, 2.2, 2.5

## DRY-PERSIST-01: Load-with-Warning + Sanitize + Test-Bypass Pattern

**Pattern:** Each persistable type (`History`, `UiState`) repeats an identical four-method scaffold using `#[cfg(not(test))]` / `#[cfg(test)]` pairs for `load()`, `load_with_warning()`, and `save()`. Each non-test load path calls `crate::config::load_json_with_warning::<Self>(FILE)`, pipes the result through `.sanitized()`, and returns `(Self, Option<String>)`. The test path returns `(Self::default(), None)`.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/history.rs` | `History::load` | 38–47 |
| 2 | `src/history.rs` | `History::load_with_warning` | 50–57 |
| 3 | `src/history.rs` | `History::save` | 61–67 |
| 4 | `src/app/ui_state.rs` | `UiState::load` | 35–44 |
| 5 | `src/app/ui_state.rs` | `UiState::load_with_warning` | 46–55 |
| 6 | `src/app/ui_state.rs` | `UiState::save` | 88–96 |

**Repeated structure (2 types × 3 methods = 6 occurrences):**

```rust
#[cfg(not(test))]
#[allow(dead_code)]
pub fn load() -> Self {
    Self::load_with_warning().0
}

#[cfg(test)]
pub fn load() -> Self {
    Self::default()
}

#[cfg(not(test))]
pub fn load_with_warning() -> (Self, Option<String>) {
    let (value, warning) = crate::config::load_json_with_warning::<Self>(FILE_CONST);
    (value.sanitized(), warning)
}

#[cfg(test)]
pub fn load_with_warning() -> (Self, Option<String>) {
    (Self::default(), None)
}

#[cfg(not(test))]
pub fn save(&self) -> anyhow::Result<()> {
    crate::config::save_json(FILE_CONST, &self.clone().sanitized())
}

#[cfg(test)]
pub fn save(&self) -> anyhow::Result<()> {
    Ok(())
}
```

**Proposed abstraction:**

```rust
// In src/config.rs — a trait + blanket or macro that provides the cfg-gated
// load/load_with_warning/save scaffold for any T: Serialize + DeserializeOwned + Default + Sanitizable

pub trait Persistable: Serialize + DeserializeOwned + Default + Clone {
    const FILE: &'static str;
    fn sanitized(self) -> Self;
}

// Blanket impl or macro generates load/load_with_warning/save with cfg gates
pub fn load_with_warning_sanitized<T: Persistable>() -> (T, Option<String>) {
    let (value, warning) = load_json_with_warning::<T>(T::FILE);
    (value.sanitized(), warning)
}

pub fn save_sanitized<T: Persistable>(value: &T) -> anyhow::Result<()> {
    save_json(T::FILE, &value.clone().sanitized())
}
```

- **Target module:** `src/config.rs` (trait definition + helpers)
- **Variation points:** File name constant (`FILE`), sanitization logic (`sanitized()`)
- **Eliminates:** 12 `#[cfg(...)]` annotations and 6 duplicated function bodies

## DRY-PERSIST-02: Read-File-or-Fallback with Warning Collection

**Pattern:** Both `config::load_json_with_warning` and `favorites::read_library_file_or_fallback` implement the same structure: attempt `fs::read_to_string`, on failure produce a warning string `"Could not read {name}; using defaults: {err}"`, and on success attempt JSON parse with a fallback warning `"Could not parse {name}; using defaults: {err}"`. The favorites version is slightly more complex (version check, station normalization) but the control flow skeleton is identical.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/config.rs` | `load_json_with_warning` | 40–57 |
| 2 | `src/config.rs` | `parse_json_with_warning` | 79–89 |
| 3 | `src/favorites.rs` | `read_library_file_or_fallback` | 470–500 |

**Shared control flow:**
```rust
match fs::read_to_string(path) {
    Ok(contents) => match parse(contents) {
        Ok(value) => (value, optional_warning),
        Err(err) => (default, Some(format!("Could not parse {name}: {err}"))),
    },
    Err(err) => (default, Some(format!("Could not read {name}: {err}"))),
}
```

**Proposed abstraction:**

```rust
// In src/config.rs — generalize with a post-parse hook
pub fn load_json_file_with_warning<T, F>(
    path: &Path,
    name: &str,
    post_parse: F,
) -> (T, Vec<String>)
where
    T: DeserializeOwned + Default,
    F: FnOnce(T) -> (T, Option<String>),
{ /* ... */ }
```

- **Target module:** `src/config.rs`
- **Variation points:** Post-parse transform (sanitize/normalize), fallback strategy (default vs seed stations), warning message label
- **Eliminates:** Repeated error-message formatting and read→parse→fallback control flow

## DRY-PERSIST-03: Flush-Persistence Save-and-Record-Error Triple

**Pattern:** In `App::try_flush_persistence_once`, three consecutive blocks follow the identical structure: check a dirty flag, call `.save()`, on success clear the flag, on failure capture the error with `PersistenceError::new(target, err)`.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/persist.rs` | `try_flush_persistence_once` (ui_state block) | 160–172 |
| 2 | `src/app/persist.rs` | `try_flush_persistence_once` (history block) | 178–186 |
| 3 | `src/app/persist.rs` | `try_flush_persistence_once` (library block) | 188–196 |

**Repeated code (3 occurrences):**
```rust
if self.persist.{target}_dirty {
    match self.{target}.save() {
        Ok(()) => self.persist.{target}_dirty = false,
        Err(err) => {
            if first_error.is_none() {
                first_error = Some(PersistenceError::new(PersistTarget::{Target}, err));
            }
        }
    }
}
```

**Proposed abstraction:**

```rust
// Helper function or macro in src/app/persist.rs
fn try_save_target(
    dirty: &mut bool,
    save_fn: impl FnOnce() -> anyhow::Result<()>,
    target: PersistTarget,
    first_error: &mut Option<PersistenceError>,
) {
    if !*dirty { return; }
    match save_fn() {
        Ok(()) => *dirty = false,
        Err(err) => {
            if first_error.is_none() {
                *first_error = Some(PersistenceError::new(target, err));
            }
        }
    }
}
```

- **Target module:** `src/app/persist.rs`
- **Variation points:** Target enum variant, save callable, dirty flag reference
- **Eliminates:** 3 identical 8-line blocks → 3 one-line calls

## DRY-PERSIST-04: "Could not save {target}: {err}" Notice Message Construction

**Pattern:** `PersistenceError::notice_message()` uses a match on `PersistTarget` where each arm produces `format!("Could not save {label}: {}", self.message)`, differing only in the label string.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/persist.rs` | `PersistenceError::notice_message` | 63–68 |

**Repeated code (3 arms, same template):**
```rust
PersistTarget::UiState => format!("Could not save UI state: {}", self.message),
PersistTarget::History => format!("Could not save history: {}", self.message),
PersistTarget::Library => format!("Could not save library: {}", self.message),
```

**Proposed abstraction:**

```rust
impl PersistTarget {
    fn label(&self) -> &'static str {
        match self {
            Self::UiState => "UI state",
            Self::History => "history",
            Self::Library => "library",
        }
    }
}

impl PersistenceError {
    fn notice_message(&self) -> String {
        format!("Could not save {}: {}", self.target.label(), self.message)
    }
}
```

- **Target module:** `src/app/persist.rs`
- **Variation points:** Target display label (derived from enum)
- **Eliminates:** Match arm duplication; automatically extensible when new persist targets are added

## DRY-NOTICE-01: "Could not {action}: {err}" Error Notice Pattern

**Pattern:** Multiple call sites across `src/app/` construct an error notice with the format `"Could not {verb} {noun}: {err}"` by inlining `self.set_error_notice(format!("Could not {action}: {err}"))`. The structure is always: attempt an operation, on `Err(err)` display notice. The format template varies only by action description.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/search.rs` | `handle_save_and_play` | 80 |
| 2 | `src/app/library.rs` | `handle_remove_station` | 37 |
| 3 | `src/app/playback.rs` | `export_library` | 233 |
| 4 | `src/app/library.rs` | `handle_metadata_refresh_result` | 133 |

**Repeated code (4 occurrences):**
```rust
Err(err) => self.set_error_notice(format!("Could not {action}: {err}"))
// or
Err(err) => self.set_error_notice(format!("{Action} failed: {err}"))
```

**Proposed abstraction:**

```rust
// In src/app/lifecycle.rs or a new src/app/notice_helpers.rs
impl App {
    pub(super) fn notify_operation_error(&mut self, action: &str, err: impl std::fmt::Display) {
        self.set_error_notice(format!("Could not {action}: {err}"));
    }
}
```

- **Target module:** `src/app/lifecycle.rs` (alongside existing `set_error_notice`)
- **Variation points:** Action description string
- **Eliminates:** Repeated `format!("Could not ...")` construction at each call site

## DRY-NOTICE-02: Sleep Timer Announcement Pattern

**Pattern:** The `announce_sleep_timer` function and the `SleepTimerClear` handler both construct notices with "Sleep timer off", while two branches in `announce_sleep_timer` construct `format!("Sleep timer: {label}")` and `format!("Sleep timer: {label} when playback starts")`. Additionally, `check_sleep_timer` constructs `"Sleep timer ended playback"`. All share the "Sleep timer" prefix and follow a status-to-message mapping.

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/sleep_timer.rs` | `announce_sleep_timer` | 183–193 |
| 2 | `src/app/sleep_timer.rs` | `SleepTimerClear` handler | 169 |
| 3 | `src/app/sleep_timer.rs` | `check_sleep_timer` | 205 |

**Repeated code (3 locations, 5 notice constructions):**
```rust
self.set_info_notice("Sleep timer off");                        // 2 occurrences
self.set_info_notice(format!("Sleep timer: {label}"));          // 1 occurrence
self.set_info_notice(format!("Sleep timer: {label} ..."));      // 1 occurrence
self.set_info_notice("Sleep timer ended playback");             // 1 occurrence
```

**Proposed abstraction:**

```rust
// In src/app/sleep_timer.rs
enum SleepTimerNotice {
    Off,
    Armed { label: String },
    WaitingForPlayback { label: String },
    Ended,
}

impl SleepTimerNotice {
    fn message(&self) -> String {
        match self {
            Self::Off => "Sleep timer off".to_string(),
            Self::Armed { label } => format!("Sleep timer: {label}"),
            Self::WaitingForPlayback { label } => format!("Sleep timer: {label} when playback starts"),
            Self::Ended => "Sleep timer ended playback".to_string(),
        }
    }
}
```

- **Target module:** `src/app/sleep_timer.rs`
- **Variation points:** Timer state (off, armed, waiting, ended)
- **Eliminates:** Scattered string literals; centralizes notice text for future i18n or wording changes

## DRY-NOTICE-03: Settings Change Confirmation Notice Pattern

**Pattern:** In `src/app/settings.rs`, each settings toggle constructs a notice with `format!("{Setting}: {value}")` immediately after applying the change and marking dirty. The structure is: update field → mark_library_dirty → set_info_notice(format!("{label}: {new_value}")).

| # | File | Function | Lines |
|---|------|----------|-------|
| 1 | `src/app/settings.rs` | `apply_selected_setting` (output device) | 73–76 |
| 2 | `src/app/settings.rs` | `apply_selected_setting` (stream metadata) | 92–98 |
| 3 | `src/app/settings.rs` | `next_theme` | 114 |

**Repeated code (3 occurrences):**
```rust
self.mark_library_dirty();
self.set_info_notice(format!("{SettingLabel}: {new_value}"));
```

**Proposed abstraction:**

```rust
impl App {
    fn confirm_setting_change(&mut self, label: &str, value: impl std::fmt::Display) {
        self.mark_library_dirty();
        self.set_info_notice(format!("{label}: {value}"));
    }
}
```

- **Target module:** `src/app/settings.rs`
- **Variation points:** Setting label, displayed value
- **Eliminates:** Repeated mark-dirty + notice pair at each settings toggle site
