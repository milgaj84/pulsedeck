## Detailed Type Breakdowns

### 1. `Action` enum — 46 variants (`src/action.rs`)

Grouped by domain responsibility:

| Category | Variants | Count |
|----------|----------|-------|
| Navigation | `NextStation`, `PrevStation` | 2 |
| Playback | `PlaySelected`, `TogglePause`, `Stop`, `RetryStream` | 4 |
| Volume | `VolumeUp`, `VolumeDown`, `ToggleMute` | 3 |
| Search | `EnterSearch`, `ExitSearch`, `SearchInput`, `SearchBackspace`, `SearchConfirm`, `SearchAudition` | 6 |
| Command Palette | `OpenCommandPalette`, `CommandPaletteConfirm`, `CommandPaletteClose`, `CommandPaletteInput`, `CommandPaletteBackspace`, `CommandPaletteNext`, `CommandPalettePrev` | 7 |
| Library | `RemoveLibrarySelection`, `UndoRemoveLibrarySelection`, `NextGenre`, `PrevGenre` | 4 |
| UI/Layout | `CycleLayout`, `ToggleHelp`, `ToggleStationDetails`, `ToggleRecentTracks`, `TogglePlaybackDoctor`, `StepSettingForward`, `StepSettingBackward`, `ToggleSettings`, `CycleThemeSetting`, `ToggleStreamMetadata`, `RefreshLibraryMetadata`, `ToggleVisualizerMode` | 12 |
| App lifecycle | `Tick`, `Quit` | 2 |
| Sleep timer | `ToggleSleepTimer`, `SleepTimerIncrease`, `SleepTimerDecrease`, `SleepTimerPreset`, `SleepTimerClear` | 5 |
| Export | `ExportLibrary` | 1 |

**Assessment:** A flat action enum is common for TUI message-loop architectures. The 46-variant count is large but functional — it serves as the single event-dispatch type. Splitting would require nested enums or submodule-scoped actions (e.g., `SearchAction`, `PaletteAction`). Medium-risk for maintenance since adding any new feature adds a variant here and in the `update()` match.
