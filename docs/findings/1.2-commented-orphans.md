## Methodology

### Commented-Out Code Detection

Scanned all `.rs` files under `src/` for blocks of ≥2 consecutive non-doc-comment lines (`//` but not `///` or `//!`) whose content matches Rust code patterns:

- Statements ending in `;`
- Keyword-starting lines: `let`, `fn`, `pub`, `use`, `mod`, `struct`, `enum`, `impl`, `type`, `const`, `static`, `trait`, `return`
- Method calls on `self.`, method chains (`.foo()`), `.await`, `->`, `=>`
- Opening/closing braces as standalone statements

**Exclusions applied:**
- Doc-comments (`///`, `//!`)
- Section divider lines (e.g., `// ─────────────────`)
- License headers (none present in this codebase)
- Explanatory comments that reference code concepts in natural English

**Result:** No commented-out code blocks found. All 590 non-doc-comment lines in the codebase are legitimate explanatory comments, section markers, or test documentation. The codebase maintains clean comment hygiene.

### Orphan File Detection

Built the complete module tree by parsing `mod` declarations from:

| Parent Module File | Declares Submodules For |
|---|---|
| `src/main.rs` | Top-level `src/*.rs` files |
| `src/app.rs` | `src/app/*.rs` files |
| `src/audio.rs` | `src/audio/*.rs` files |
| `src/radio.rs` | `src/radio/*.rs` files |
| `src/ui/mod.rs` | `src/ui/*.rs` files |
| `src/app/visualizer/mod.rs` | `src/app/visualizer/*.rs` files |
| `src/ui/deck/mod.rs` | `src/ui/deck/*.rs` files |
| `src/ui/deck/visualizer/mod.rs` | `src/ui/deck/visualizer/*.rs` files |
| `src/ui/theme/mod.rs` | `src/ui/theme/*.rs` files |

Every `.rs` file under `src/` was verified against its parent module's `mod` declarations.

**Result:** No orphan files found. All 58 source files are properly declared in their parent module tree and reachable from the crate root (`src/main.rs`).
