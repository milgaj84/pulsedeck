## 4. Flattening Proposals (Deep Nesting)

### 4.1 `consume_metadata_block` — `src/audio/stream_source.rs` L108–135 (depth 5)

**Current structure:**
```
if body_len > 0 {
    if let Ok(meta_str) = String::from_utf8(body) {
        if let Some(title) = parse_stream_title(&meta_str) {
            if changed {
                send event
            }
        }
    }
}
```

**Proposal: Early returns + guard clauses**
```rust
fn consume_metadata_block(&mut self, demux: &mut IcyDemux) -> io::Result<()> {
    // ... read len_byte ...
    if body_len == 0 {
        demux.bytes_until_next_meta = demux.metaint;
        return Ok(());
    }

    let body = /* read */;
    let Ok(meta_str) = String::from_utf8(body) else {
        demux.bytes_until_next_meta = demux.metaint;
        return Ok(());
    };

    let Some(title) = parse_stream_title(&meta_str) else {
        demux.bytes_until_next_meta = demux.metaint;
        return Ok(());
    };

    if self.last_title.as_deref() != Some(title.as_str()) {
        self.last_title = Some(title.clone());
        let _ = self.event_tx.send(EngineEvent::TrackChanged { ... });
    }

    demux.bytes_until_next_meta = demux.metaint;
    Ok(())
}
```
Reduces nesting from 5 → 1.

### 4.2 `fail_or_recover` — `src/audio/engine_loop_v2.rs` L333–379 (depth 5)

**Current structure:**
```
if recoverable && retries < MAX {
    match self.output.reopen() {
        Ok(()) => {
            if let Some(url) = url {
                // spawn reconnect (depth 5)
            } else {
                // emit error
            }
        }
        Err(e) => { ... }
    }
} else {
    // emit error
}
```

**Proposal: Early return for non-recoverable case, then extract `attempt_hardware_recovery`**
```rust
fn fail_or_recover(&mut self, error: EngineError, url: Option<String>) {
    if !error.is_recoverable_output()
        || self.output.recovery_retries() >= MAX_HARDWARE_RECOVERY_RETRIES
    {
        self.emit_failure(error, url);
        return;
    }

    match self.output.reopen() {
        Ok(()) => self.reconnect_after_reopen(url, error),
        Err(reopen_err) => self.emit_failure(reopen_err, url),
    }
}
```
Reduces nesting from 5 → 2.

### 4.3 `handle_event` (Buffering arm) — `src/audio/engine_loop_v2.rs` L205–224 (depth 5)

**Current structure:**
```
match ev {
    Buffering { percent, generation } => {
        let new_state = match &self.state {
            Connecting { url, .. } => Some(Buffering { ... }),
            Buffering { url, .. } => Some(Buffering { ... }),
            _ => None,
        };
        if let Some(next) = new_state {
            self.transition_to(next);
        }
    }
}
```

**Proposal: Extract to method**
```rust
fn handle_buffering(&mut self, percent: u8, generation: u64) {
    let url = match &self.state {
        EngineState::Connecting { url, .. } | EngineState::Buffering { url, .. } => url.clone(),
        _ => return,
    };
    self.transition_to(EngineState::Buffering { generation, url, percent });
    self.emit(AudioStatus::Buffering { percent });
}
```
Reduces nesting from 5 → 1.

### 4.4 `render_visualizer_signal` — `src/ui/deck/visualizer/mod.rs` L36–140 (depth 5)

**Current nesting:** `match state { Playing => match mode { 1 => { if let Ok(buf) { if n >= pw { … } } } } }`

**Proposal:** Extract each visualization mode into its own function (see §2.3 above). The lock-and-extract pattern:
```rust
fn extract_waveform_samples(buffer: &Mutex<VecDeque<f32>>, pixel_width: usize) -> Vec<f32> {
    let Ok(buf) = buffer.lock() else { return vec![0.0; pixel_width] };
    let n = buf.len();
    if n >= pixel_width {
        buf.iter().skip(n - pixel_width).take(pixel_width).copied().collect()
    } else {
        let mut samples = vec![0.0; pixel_width - n];
        samples.extend(buf.iter().copied());
        samples
    }
}
```
Reduces nesting from 5 → 1.
