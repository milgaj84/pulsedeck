### Key Observations

1. **No `dead_code`, `unused_variables`, or `unused_imports` warnings were raised** — all such items are explicitly suppressed by `#[allow(dead_code)]` annotations rather than being removed.
2. **10 functions** marked `#[allow(dead_code)]` are only used from test code and should either be moved to `#[cfg(test)]` modules or removed.
3. **`StreamFormat`** is constructed, passed through a channel, and then discarded (`format: _`) — the entire struct and its fields are dead data in the current implementation.
4. **`EngineState::Recovering`**, **`DecoderState::Probing`/`Ended`**, **`EndReason::Network`/`Decode`**, and **`EngineError::Abandoned`** are enum variants that are never constructed in production, suggesting incomplete feature implementation or premature abstraction.
5. The **`never_loop`** error in `decode.rs:422` indicates a degenerate loop that always breaks on first iteration — this is dead control flow that should be replaced with a simple `if` block.
