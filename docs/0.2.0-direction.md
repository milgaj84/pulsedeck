# PulseDeck 0.2.0 direction

PulseDeck 0.2.0 is a focused product reset.

The app is narrowing around fast, reliable terminal radio playback:
- station discovery
- saved library management
- playback controls
- themes
- visualizers
- audio output reliability
- polished terminal UX

PulseDeck 0.2.0 removes recording, local tape archive management, local tape playback, and recording recovery workflows.

Reason:
The recording/tape system added significant complexity to the app, UI, audio engine, settings, tests, and maintenance surface. The 0.2 line prioritizes a simpler, sharper radio-player experience.
